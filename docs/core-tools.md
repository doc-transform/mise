# 核心工具

`mise` 内置了一些用 Rust 编写的插件。这些插件还比较新，会随着时间不断完善。

安装同名的 asdf/vfox 插件即可轻松覆盖内置核心插件，例如：`mise plugin install python https://github.com/asdf-community/asdf-python`。

你可以通过 `mise registry -b core` 查看所有核心插件。
