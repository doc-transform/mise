# S3 工具源 <Badge type="warning" text="experimental" />

你可以使用 `s3` 工具源直接从 Amazon S3 或兼容 S3 的存储（如 MinIO）安装工具。此工具源非常适合在私有 S3 存储桶中托管专有工具的企业团队。

相关代码位于 mise 仓库的 [`./src/backend/s3.rs`](https://github.com/jdx/mise/blob/main/src/backend/s3.rs)。

::: warning
S3 工具源是实验性的，需要在 mise 设置中启用 `experimental = true`。
:::

## 用法

以下命令从 S3 存储桶安装工具：

```sh
mise use -g "s3:my-tool[url=s3://my-bucket/tools/my-tool-v1.0.0.tar.gz]@1.0.0"
```

版本将以如下格式写入 `~/.config/mise/config.toml`：

```toml
[tools]
"s3:my-tool" = { version = "1.0.0", url = "s3://my-bucket/tools/my-tool-v1.0.0.tar.gz" }
```

## 认证

S3 工具源使用 AWS SDK 的默认凭证链。凭证按以下顺序加载：

1. 环境变量：`AWS_ACCESS_KEY_ID` 和 `AWS_SECRET_ACCESS_KEY`
2. AWS 凭证文件：`~/.aws/credentials`
3. IAM 角色（在 AWS 基础设施上运行时）

```sh
# 通过环境变量设置凭证
export AWS_ACCESS_KEY_ID="your-access-key"
export AWS_SECRET_ACCESS_KEY="your-secret-key"
export AWS_DEFAULT_REGION="us-east-1"

mise install
```

## 工具选项

以下[工具选项](/dev-tools/#tool-options)可用于 `s3` 工具源——在 `mise.toml` 的 `[tools]` 中配置。

### `url`（必需）

指定下载工具的 S3 URL。URL 支持使用 `{{ version }}` 进行模板化：

```toml
[tools]
"s3:my-tool" = { version = "1.0.0", url = "s3://my-bucket/tools/my-tool-v{{ version }}.tar.gz" }
```

### `endpoint`

为 MinIO、DigitalOcean Spaces 或自托管 S3 等服务指定自定义的 S3 兼容端点：

```toml
[tools."s3:my-tool"]
version = "1.0.0"
url = "s3://my-bucket/tools/my-tool-v{{ version }}.tar.gz"
endpoint = "http://minio.internal:9000"
```

### `region`

指定 S3 存储桶的 AWS 区域：

```toml
[tools."s3:my-tool"]
version = "1.0.0"
url = "s3://my-bucket/tools/my-tool-v{{ version }}.tar.gz"
region = "us-west-2"
```

### 特定平台的 URL

对于需要为不同平台提供不同下载的工具，使用表格格式：

```toml
[tools."s3:my-tool"]
version = "1.0.0"

[tools."s3:my-tool".platforms]
macos-x64 = { url = "s3://my-bucket/tools/my-tool-v1.0.0-macos-x64.tar.gz" }
macos-arm64 = { url = "s3://my-bucket/tools/my-tool-v1.0.0-macos-arm64.tar.gz" }
linux-x64 = { url = "s3://my-bucket/tools/my-tool-v1.0.0-linux-x64.tar.gz" }
```

### `checksum`

使用校验和验证下载的文件：

```toml
[tools."s3:my-tool"]
version = "1.0.0"
url = "s3://my-bucket/tools/my-tool-v1.0.0.tar.gz"
checksum = "sha256:a1b2c3d4e5f6789..."
```

_你也可以使用 [mise.lock](/dev-tools/mise-lock) 来管理校验和，而不是在此处指定。_

### `bin_path`

指定解压归档文件中包含二进制文件的目录：

```toml
[tools."s3:my-tool"]
version = "1.0.0"
url = "s3://my-bucket/tools/my-tool-v1.0.0.tar.gz"
bin_path = "my-tool-{{ version }}/bin"
```

### `format`

当 URL 没有文件扩展名时，显式指定归档格式：

```toml
[tools."s3:my-tool"]
version = "1.0.0"
url = "s3://my-bucket/tools/my-tool-v1.0.0"
format = "tar.gz"
```

## 版本发现

S3 工具源支持两种发现可用版本的方式。

### 清单文件

从存储在 S3 中的 JSON 清单文件获取可用版本：

```toml
[tools."s3:my-tool"]
version = "latest"
url = "s3://my-bucket/tools/my-tool-v{{ version }}.tar.gz"
version_list_url = "s3://my-bucket/tools/versions.json"
```

清单文件可以是版本字符串的 JSON 数组：

```json
["1.0.0", "1.1.0", "2.0.0"]
```

或 JSON 对象数组（使用 `version_json_path` 提取版本）：

```json
[{ "version": "1.0.0" }, { "version": "1.1.0" }, { "version": "2.0.0" }]
```

### `version_json_path`

使用类 jq 的路径表达式从 JSON 响应中提取版本：

```toml
[tools."s3:my-tool"]
version = "latest"
url = "s3://my-bucket/tools/my-tool-v{{ version }}.tar.gz"
version_list_url = "s3://my-bucket/tools/releases.json"
version_json_path = ".[].version"
```

### `version_expr`

使用 [expr-lang](https://expr-lang.org/) 表达式提取版本，适用于复杂的版本提取逻辑：

```toml
[tools."s3:my-tool"]
version = "latest"
url = "s3://my-bucket/tools/my-tool-v{{ version }}.tar.gz"
version_list_url = "s3://my-bucket/tools/versions.txt"
version_expr = 'split(body, "\n")'
```

表达式接收响应体作为 `body` 变量，应返回版本字符串数组。

### S3 对象列表

通过列举 S3 存储桶中的对象来发现版本：

```toml
[tools."s3:my-tool"]
version = "latest"
url = "s3://my-bucket/tools/my-tool-v{{ version }}.tar.gz"
version_prefix = "tools/my-tool-v"
version_regex = "my-tool-v([0-9.]+)"
```

- `version_prefix`：用于列举对象的 S3 键前缀
- `version_regex`：用于从对象键中提取版本号的正则表达式（使用第一个捕获组）

## 自定义端点示例（MinIO）

以下是使用 MinIO 作为 S3 兼容工具源的完整示例：

```toml
[tools."s3:my-internal-tool"]
version = "latest"
url = "s3://tools-bucket/releases/my-tool-{{ version }}.tar.gz"
endpoint = "http://minio.internal:9000"
region = "us-east-1"
version_list_url = "s3://tools-bucket/releases/versions.json"
bin_path = "bin"
```

配合环境变量：

```sh
export AWS_ACCESS_KEY_ID="minio-access-key"
export AWS_SECRET_ACCESS_KEY="minio-secret-key"
mise install
```

## 与 HTTP 工具源的比较

| 功能           | S3 工具源                                              | HTTP 工具源       |
| -------------- | ------------------------------------------------------ | ----------------- |
| 认证           | AWS 凭证（环境变量、~/.aws/credentials、IAM）          | HTTP 认证头       |
| 版本发现       | S3 列表或清单文件                                      | HTTP 端点         |
| 自定义端点     | 支持（MinIO 等）                                       | 不适用            |
| 适用场景       | 私有/企业工具                                          | 公开下载          |
